# 2026-10-09 機能統合レビュー

旧 main `d4a3694` と、PR #1 `9067567`・PR #2 `e96fa297` を比較し、
Python を同梱しない条件で以下のソース版機能を統合対象としました。

## 採用する機能

- CMD によるセットアップ・起動、明示した Python 本体の利用、プロキシ・CA・オフライン wheel、失敗段階の診断。
- 3列の操作画面、エージェント一覧・親子図、全チームの質問一覧、成果・保存記録、依頼の再利用。
- 送信の受付確認が取れない場合の下書き保持、設定保存の競合防止、資格情報の更新、IME 変換中の誤送信防止。
- Office 文書などに対するテキスト操作での誤上書き拒否、既知の秘密値の表示マスク、Web 文字コード処理。
- 上限付きの会話要約と元履歴の参照。自動連携は既定24回、作業者数と Local 推論同時数は別設定のまま。

## Python を同梱しない

通常版の 64-bit CPython 3.11〜3.13 をアプリとは別に導入し、
`WORKBENCH_PYTHON` に本体のパスを指定します。アプリは Python 本体を
ダウンロード・インストールしません。仮想環境は利用する PC 上で作成し、
ソース配布物にコピーしません。

同梱ビルダーの CLI・直接 assembly・PyInstaller spec は評価用も含め実行を拒否します。
同梱版を生成する CI ジョブはなく、追跡ファイルにも exe / dll / pyd / whl / zip はありません。
通常の依存 lock は旧 main から変更なしです。過去のビルド補助コード・専用 lock・
検証記録は履歴として残っており、現在利用できる同梱版や再開計画を意味しません。

## 利用時に変わる点と残る制約

- 会話の自動要約は既存設定にも既定 ON で加わります。設定で OFF にできます。
  同じプロファイル・モデルへの追加呼び出しで、既存のモデル回数・時間予算を消費します。
  要約にツール実行権限はなく、要約だけを根拠にアクセス権限を拡大しません。
- 要約では情報が抜けることがあります。元履歴はエージェント別に既定40万文字・最大2000レコードで、
  古い内容は保持上限から除外されます。履歴・実行状態・画面入力したキーはプロセス終了で失われます。
- Local 推論は環境変数のプロキシを引き継がず、明示プロキシも使用しません。
  クラウドAPIとWeb検索・取得の設定は別です。
- 許可フォルダーは OS 全体のサンドボックスではありません。読み取りを許可した内容は、
  混成チームのメールやWeb検索語・URLを通じ外部へ渡り得ます。DLPや完全なプロンプトインジェクション防止ではありません。
- GPU/VRAM の条件は推論開始時の判定で、外部 LLM サーバーの割り当て容量を強制制限しません。
