# SKILL.md で作業手順を共有する

スキルは、PM と作業者が必要に応じて読む手順書です。ユーザーの作業フォルダーに置き、設定の「読み取りを許可する場所」にそのフォルダーを登録します。アプリのインストール先や設定保存先は自動保護されるため、別の作業フォルダーを使ってください。

## 置き場所と最小例

たとえば `C:\Projects\research` を読み取り許可した場合、次のいずれかに置けます。

```text
C:\Projects\research\skills\weather-table\SKILL.md
C:\Projects\research\.agents\skills\weather-table\SKILL.md
```

最小の `SKILL.md` は次のように書きます。UTF-8 で保存してください。

```markdown
---
name: weather-table
description: 必要な地域と日付の天気を調べて表にまとめる手順。
---

# 天気を表にまとめる

1. 依頼された地域、日付、必要な項目を確認する。
2. 必要な地域と期間に絞って一次情報を取得する。
3. 取得日時と出典 URL を表に付ける。
4. 指定された保存先へ保存し、内容を読み戻して確認する。
```

先頭の `---` で囲んだ部分は front matter です。これを書く場合は `name` と `description` の両方が必要です。対応するのは次の小さなサブセットです。

- 通常の文字列、単一引用符、JSON 形式の二重引用符、複数行の `|`／`>`。引用符なしの数値・真偽値・配列・オブジェクト・タグなどは名前や説明として受け付けません。
- `name` は 1〜128 文字、`description` は 1〜512 文字。表示用の連続した空白・改行は空白一つにまとめます。同じ必須フィールドの重複はエラーです。
- それ以外のメタデータは解釈せず無視します。`allowed-tools` などを書いても権限は追加されません。
- UTF-8 の BOM と CRLF に対応します。front matter がない場合はフォルダー名をスキル名、最初の空でない行を説明に使います。

一般的な YAML パーサーではありません。複雑な設定を front matter へ入れず、手順はその後の本文に書いてください。

## 一覧を確認して使う

1. 設定の「ファイルへのアクセス」で読み取り許可を保存します。
2. その下の「スキル（SKILL.md）」で「保存済み設定で一覧を再読込」を押します。名前・説明・場所・読み込んだ版の SHA-256 と、読込エラーを確認できます。未保存の設定は使いません。
3. 新しい作業を開始します。依頼文に「`$weather-table` を使って関東地方の明日の天気を Excel にまとめて」のように名前を指定できます。

PM と作業者には利用できるスキルの一覧が渡り、本文は `read_skill` で必要なものを読みます。同名のスキルも別の場所なら別の ID で掲載されます。設定画面の「場所と読み込んだ版を確認」を開いて区別でき、モデル側では一意なスキル ID を指定して読みます。同名があるときは設定画面に表示されたスキル ID を依頼にも添えてください。名前の指定だけでどちらかを無条件に選ぶ前提にはしないでください。

新しい作業では開始時に取り込んだ SKILL.md の内容を保持します。ファイルを編集した後の内容は次の作業から使います。設定画面の一覧の再読込で実行中の手順は差し替わりません。一覧への掲載や `$name` の指定は、モデルが手順どおりに完了したことの証明ではありません。

## 参照ファイルとスクリプト

スキルに `references/checklist.md` のような相対位置を書く場合、SKILL.md のあるフォルダーが基準です。`read_skill` が返す基準フォルダーを確認し、モデルは既存のファイル読取ツールで許可されたファイルを読みます。参照ファイルは SKILL.md と一緒に自動読込されず、後で読む時点のファイルが対象です。

`scripts/` にスクリプトを置いても、自動実行・依存ライブラリの自動インストールはしません。スキルはファイルの許可範囲、無効な機能、ツールの利用権限、推論・ツール・時間の予算を変更しません。ファイルの拒否設定やアプリ・設定保存先の保護は引き続き優先されます。スキル本文に権限変更や外部送信の指示を書いても、それだけでユーザーの承認にはなりません。

## 読込エラー

SKILL.md は 1 ファイル 32 KiB、スキルは 32 件、探索は 256 件の訪問、本文の読込合計は 1 MiB までに制限されます。拒否された項目も探索数に数えます。大きな資料を本文へ詰め込まず、必要な参照を別ファイルに分けてください。設定のファイルサイズ上限がこれより小さければ、その上限も適用されます。

読込エラーには、形式や文字コードの不正、上限超過、権限外、同じフォルダーに大文字・小文字だけが異なる複数の SKILL.md 候補がある状態などがあります。エラーを表示した一覧を、すべてのスキルを読み込めた状態と扱わないでください。ファイルを修正して明示的に再読込し、次の作業を開始します。シンボリックリンク・ジャンクションなど、既存のファイル境界が拒否する経路は使えません。
