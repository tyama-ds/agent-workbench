# 動的ネットワーク表示

丸ひとつがPMまたはワーカーです。PMは金色、ワーカーは水色を基調にし、
状態は色に加えて文字でも表示します。親子の細い線と、記録されたメールの
方向を示す破線は区別しています。配置は実際の親子関係から決めます。

## 概要とピン留め

- 丸にマウスを重ねるか、Tabでフォーカスすると担当・状態・最新記録を表示します。
- クリックまたはEnterで概要を固定します。同じ丸をもう一度押すと解除します。
- 固定中は別の丸にマウスを重ねても表示を切り替えません。
- Escapeまたは概要の閉じるボタンで解除できます。
- 「担当ログを開く」で選択担当の全文へ移ります。丸にフォーカスした状態でF2を押すと、このボタンへ移動できます。

概要表示とピン留めでは、指示の送信、追加の情報取得、担当ログの選択変更を
行いません。入力途中の下書きも変えません。固定中の概要は画面に届いた
最新の公開記録から更新します。最新記録は現在の処理や内容理解の保証ではありません。

## 動きの意味

公開状態が作業中の担当には、周囲を巡るリングを表示します。これは
推論のトークン生成やCPU使用率を測った表示ではありません。

新しく観測した実メールのイベントだけを、流れる粒と受信側のリングで示します。

| 表示 | 対応する記録 | 意味 |
|---|---|---|
| 水色の粒 | 送信受付 | 宛先のキューへ受理された |
| 宛先に広がる金色のリング | 会話への取り込み | モデルへ送る会話に含まれた |

受付と取り込みは別の段階です。取り込みも、理解・対応・正式報告・作業完了を
保証しません。矢印をクリックすると、その二者の通信記録を確認できます。
通信相手を特定できない古い記録から粒を作ることはありません。

最初に画面を開いたとき、履歴を開いたとき、作業を切り替えたとき、再接続した
ときは過去の通信を再生しません。通信は画面へ届いた時点で短く表示するため、
実際のネットワーク転送を同期計測したものではありません。表示中の最新100件から
最大12方向を描き、同時に表示する粒も制限します。

「動き」ボタンでアニメーションを止められます。OSの「動きを減らす」設定を
優先し、接続切れ、別のブラウザータブや表示モードへの切り替え、設定・依頼ダイアログの表示中、終了済み・保存済みの作業では動かしません。単なるスクロールで図が画面外に出た場合の停止は行いません。
停止中の通信を後からまとめて再生することもありません。

## 配置の操作

丸のドラッグで配置、背景のドラッグで表示位置を変えられます。倍率ボタン、
Ctrl＋ホイール、全体表示、配置を戻す操作も使えます。図にフォーカスして
矢印で移動、＋/−で倍率変更、Homeで全体表示。担当はAlt＋矢印で移動できます。

配置・表示位置・ピン留めはブラウザーのメモリー内で作業ごとに保持し、最大64作業
です。永続的な設定や担当関係、権限、実行内容は変えません。サーバーの入れ替わり、
秘密情報のマスク更新、削除された担当には古い概要を残しません。
