- Web decoding is strict and source-labelled. Task/history guidance explains file/Web prerequisites, no arbitrary command execution, and the different effects of tab reload, Stop and server exit. There is no automatic history backup/restore.
- Tool failures preserve truthful result closure and prior receipts; provider completion evidence gates reports/calls and Local refusals remain replayable. Queued file operations recheck deadlines after acquiring the lock, while already-started saves still drain.

Valid acceptance reconciles the saved baseline without overriding newer drafts or dialog feedback. Task drafts retain empty workers, unavailable profiles and above-limit counts. Unknown/conflicting outcomes block resending, keys and diagnostics until explicit saved-settings reload; ordinary fields remain editable. There is no automatic retry, merge or reload.
