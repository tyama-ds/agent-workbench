WORKSPACE SETTINGS
CONFIGURATION
作業環境を整える。
使うモデル、アクセスできる場所、実行の上限を設定します。

        

          
モデルのプロファイル
同じサービスに複数のモデルを登録できます。モデル名は自由に指定できます。

          
ファイルへのアクセス
絶対パスを1行に1つ入力してください。拒否する場所は許可より優先されます。

          
Web 検索
検索サービスの接続先と、必要な環境変数を指定します。
未入力のままなら、指定した環境変数を使用します。

          
ローカルモデルの実行制御
人数に関わらず、Local 全体のリクエスト数・待ち時間を制御します。リクエスト上限は、プロファイルの設定値にも適用されます。
GPU のしきい値はリクエスト開始前の確認です。モデルの VRAM 割り当て量を強制的に制限する機能ではありません。確認対象はこの PC の GPU です。別の PC にある Local API では使用できません。

          
作業の上限
自動連携、呼び出し回数、時間、コンテキスト、出力の予算を設定します。変更は新しい作業に適用されます。

          
共通の作業方針
PM と作業者に共有する指示です。作業を始める前に確認・編集できます。
