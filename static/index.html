文章の整理や、許可したファイルの読み書きを依頼できます。Python を設定・有効化すると計算やデータ処理も実行できます。任意のシェルコマンドは実行できません。

            
依頼例と必要な設定

              
文章だけで始める
例：次のメモを、決定事項・担当・期限に整理し、不明点を列挙してください。続けてメモ本文を貼り付けます。
使うモデルの設定が必要です。ファイルの許可や Web の設定は不要です。作業者の上限を 0 にすると PM だけで作業します。

              
許可したファイルを使う
例：指定した入力フォルダーの資料を要約し、指定した出力フォルダーに reports フォルダーを作成し、その中へ summary.docx を保存してください。元資料は変更しないでください。
設定 → ファイルへのアクセスで、入力先を「読み取りを許可する場所」、出力先を「書き込みを許可する場所」に登録します。既存フォルダーの絶対パスを使い、設定を保存してから新しい作業を開始してください。依頼文にパスを書くことだけでは許可されません。
許可した出力先の中で、サブフォルダーと UTF-8 テキスト・対応する .docx / .xlsx / .pptx を作成できます。Word・Excel・PowerPoint の読み取り・作成・対応箇所の編集にも使えます。名前でファイルやフォルダーを探す場合は search_paths、テキスト本文を探す場合は search_text を使うよう依頼してください。文章の起案だけを希望する場合は、その旨を依頼してください。実際のファイル保存は担当者の「成果・保存記録」で確認できます。ファイル削除はできません。

              
Python で計算・データ処理をする
例：指定した CSV を Python で集計し、計算結果を確認して result.xlsx に保存してください。
設定 → Python スクリプト実行で、既存の python.exe とライブラリを指定して有効にします。明示した入力ファイルを隔離した作業場所へコピーし、明示した出力だけを許可先へ保存します。ネットワーク接続は既定でオフです。必要な場合は設定で許可すると直接通信できます。シェル・子プロセスの起動はできません。Python の同梱やパッケージの自動インストールは行いません。

              
公開 Web の資料を調べる
例：指定したテーマを公開 Web で調べ、参照した URL と要点、確認できなかった点をまとめてください。
設定で Web を有効にします。DuckDuckGo は API キー不要です。SearXNG を使う場合は検索サーバーの URL を設定します。検索とページ取得の利用状態は「開始前の確認」で確認してください。ページ取得は公開 HTTP(S) テキストが対象で、ログインや JavaScript の実行はできません。

              
ブラウザー画面を操作する
例：指定した URL を開き、検索欄にキーワードを入力して、表示された結果のテキストと PNG を許可した出力先に保存してください。
設定 → Selenium ブラウザー操作で既存のブラウザー・WebDriver・ライブラリを指定して許可します。Python の実行ファイルの指定とネットワーク接続の許可も必要です。通常の Python スクリプト実行を有効にする必要はありません。専用の新しいブラウザーを画面なしで毎回起動し、Python のフォルダー隔離は適用されません。任意の JavaScript 実行やファイルのアップロード・ダウンロードはできません。

設定の引き継ぎ
同じPC・同じユーザーで通常起動すれば、アプリを更新しても保存済み設定を引き継ぎます。
バックアップ、または以前の settings.json を読み込めます。読み込んだ内容を確認して「設定を保存」を押してください。移動したフォルダーや実行ファイルの場所は修正してください。直接入力したAPIキー・会話・実行履歴は含みません。

          
API キーを直接入力し、保存方法を選べます。既定は「この起動中のみ」です。「このWindowsユーザーに暗号化保存」を明示して保存すると、同じPC・同じWindowsユーザー・同じ保存先で再起動や更新後も使えます。設定・履歴のバックアップにキーは含みません。値は取得・再表示しません。同じ保存済みプロファイルを使うすべてのチームの次のリクエストに反映され、送信済みのリクエストは変わりません。保存だけで接続確認・自動再試行・プロファイルの有効化は行いません。
暗号化保存の利用状態は未確認です。

          

          
Copilot-agent mode
既存の copilot-bridge を起動して、Copilot Agent を新しい作業の接続先候補の先頭に表示します。
オンにして保存するとBridgeの準備を始めます。Edgeが開いた場合は必要に応じてサインインしてください。未入力の新しい作業ではPMと作業者にCopilot Agentを優先し、入力済みの下書きや明示した別の接続先は保持します。既存のモデルプロファイルは書き換えません。

ファイルへのアクセス
絶対パスを1行に1つ入力してください。拒否する場所は許可より優先されます。

          
Python スクリプト実行
既存の Python とライブラリで通常のスクリプトを実行します。既定は無効です。Python の同梱・自動インストールは行いません。
ネットワーク接続は既定でオフです。オンにすると、Python が Web 検索のプロキシ設定を使わず直接通信し、入力ファイル・ライブラリなど読み取れるデータを外部へ送信できます。LAN 内からの着信も許可対象になります。保存後に開始した新しい作業に適用されます。localhost（loopback）への接続には Windows の制限が残る場合があります。
Windows の隔離実行に必要な条件を満たす場合だけ実行できます。実行時の確認に失敗した場合も停止し、無制限な実行へ切り替えません。シェル・子プロセスの起動はできません。選択した Python 環境とライブラリは読み取り制限の例外になるため、場所を確認して指定してください。
処理するファイルは許可範囲から明示した入力だけをコピーします。明示した出力だけを許可した保存先へ書き戻します。元のフォルダーへ Python が直接アクセスする方式ではありません。通常のフォルダー許可とは別に、選択した環境・ライブラリと OS の基本情報（レジストリ）の読み取り、隔離用の専用プロファイル・一時領域への書き込みを許可します。Windows が隔離アプリ向けに公開済みの場所は、拒否フォルダーの設定とは別に直接読める場合があります。

          
Selenium ブラウザー操作
既存の Edge / Chrome と WebDriver、Selenium ライブラリを指定します。既定は無効です。ダウンロード・インストールは行いません。
上の Python 設定の python.exe を使います。「Python スクリプト実行を有効にする」は不要ですが、「Python のネットワーク接続を許可」は必要です。設定を保存した後に開始する新しい作業に適用されます。
通常の Windows ユーザー権限で、操作のたびに専用の新しい headless ブラウザー（画面なし）を起動します。Python の LPAC によるフォルダー隔離は適用されません。ファイルへのアクセス設定はスクリーンショット保存などツールによる転送だけに適用されます。普段のブラウザープロファイルは使いませんが、企業 SSO などの完全な隔離は保証できません。
URL の表示・クリック・フォーム入力・テキスト取得・PNG 保存に対応します。任意の JavaScript 実行、ファイルのアップロード・ダウンロードはできません。通常の Python スクリプトからシェル・子プロセスを起動することは引き続きできません。
Selenium 専用プロキシは空欄なら直接接続します。Web 検索のプロキシ設定は引き継ぎません。

          
Web 検索・ページ取得
DuckDuckGo は API キー不要です。接続先 URL は固定です。SearXNG を使う場合だけ検索サーバーの URL を指定します。検索方式を変更しても、この機能は自動で有効になりません。

          
ローカルモデルの実行制御
人数に関わらず、Local 全体のリクエスト数・待ち時間を制御します。リクエスト上限は、プロファイルの設定値にも適用されます。
GPU のしきい値はリクエスト開始前の確認です。モデルの VRAM 割り当て量を強制的に制限する機能ではありません。確認対象はこの PC の GPU です。別の PC にある Local API では使用できません。

          
作業の上限
自動連携、呼び出し回数、時間、コンテキスト、出力の予算を設定します。変更は新しい作業に適用されます。

          
共通の作業方針
PM と作業者に共有する指示です。作業を始める前に確認・編集できます。
